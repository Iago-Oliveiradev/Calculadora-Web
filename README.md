# Calculadora Web

Uma calculadora desenvolvida com **HTML, CSS e JavaScript**, com interface simples e operações matemáticas básicas. O projeto foi criado como prática de desenvolvimento Front-End, aplicando conceitos de estruturação, estilização e manipulação do DOM.

## Funcionalidades

- Operações de adição, subtração, multiplicação e divisão.
- Entrada de números inteiros e decimais.
- Botão `CE` para limpar a operação.
- Botão `DEL` para apagar o último caractere.
- Tratamento de divisão por zero.
- Interface interativa com efeitos visuais nos botões.

## Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização, Flexbox e CSS Grid.
- **JavaScript:** lógica das operações, eventos e manipulação do DOM.

## Objetivo do projeto

O objetivo deste projeto é consolidar conhecimentos fundamentais de desenvolvimento Front-End, especialmente a integração entre HTML, CSS e JavaScript, além da construção de interfaces e implementação de funcionalidades utilizando JavaScript puro (*Vanilla JavaScript*).
